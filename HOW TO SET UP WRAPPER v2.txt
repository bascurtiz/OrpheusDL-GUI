macOS — step-by-step (Intel and Apple Silicon)
----------------------------------------------------------------------------
Works for both architectures; the few commands that differ are marked.

0. Install Docker Desktop for Mac: https://www.docker.com/products/docker-desktop
   - Apple Silicon: install the arm64 build.
   - Intel Mac: install the x86_64 build.
   If Docker is already installed, ditch any container, image, volume and
   build to start fresh.

1. Get wrapper-v2: https://github.com/glomatico/wrapper-v2
   Click "Code" → "Download ZIP", extract the zip (e.g. to ~/Downloads/wrapper-v2-main).

2. Download Apple Music Android 3.6.0-beta build 1109:
   https://www.apkmirror.com/apk/apple/apple-music/apple-music-3-6-0-beta-release/apple-music-3-6-0-beta-4-android-apk-download/
   Move it into the extracted wrapper-v2 folder and rename it to apple-music.apkm
   (adjust the paths if your download landed elsewhere)

3. Open Terminal and go into the wrapper-v2 folder:
       cd ~/Downloads/wrapper-v2-main

4. Extract the Apple Music native libraries (takes ~1 min):
   Apple Silicon (M1/M2/M3/M4):
       bash tools/extract-libs.sh --bundle apple-music.apkm --arch arm64-v8a
   Intel Mac:
       bash tools/extract-libs.sh --bundle apple-music.apkm --arch x86_64

5. Stage the system libs, then swap in WorldObservationLog's Apple libs.
   The APK's Apple libs are missing the getPersistentKey symbol that
   wrapper-v2's FairPlay path needs; the WorldObservationLog release libs
   export it. Do NOT "git clone" WorldObservationLog/wrapper — its main
   branch commits x86_64 libs and breaks the arm64 build with
   "libc++_shared.so is incompatible with aarch64linux". Use the release
   zip for YOUR architecture instead.

   Apple Silicon (M1/M2/M3/M4):
       bash tools/stage-system.sh --arch arm64-v8a

       curl -fLo /tmp/wol-arm64.zip "https://github.com/WorldObservationLog/wrapper/releases/download/wrapper.arm64.latest/Wrapper.arm64.latest.zip"
       unzip -oq /tmp/wol-arm64.zip -d /tmp/wol-arm64

       cp -a /tmp/wol-arm64/rootfs/system/lib64/. rootfs/system/lib64/
       bash tools/stage-system.sh --arch arm64-v8a

   Intel Mac:
       bash tools/stage-system.sh --arch x86_64

       curl -fLo /tmp/wol-x86.zip "https://github.com/WorldObservationLog/wrapper/releases/download/wrapper.x86_64.latest/Wrapper.x86_64.latest.zip"
       unzip -oq /tmp/wol-x86.zip -d /tmp/wol-x86

       cp -a /tmp/wol-x86/rootfs/system/lib64/. rootfs/system/lib64/
       bash tools/stage-system.sh --arch x86_64

6. Make sure Docker Desktop is running, then rebuild:
   Apple Silicon (native arm64 image, no emulation — recommended):
       docker compose down
       TARGET_ARCH=arm64-v8a RUNTIME_PLATFORM=linux/arm64 docker compose up --build

   Intel Mac (amd64 image):
       docker compose down
       docker compose up --build

   You should eventually see:
       wrapperd: 0.0.2 HTTP listening on 0.0.0.0:80
       wrapperd: 0.0.2 TCP decrypt listening on 0.0.0.0:10020
       wrapper-v2: ipc worker ready

7. Verify the wrapper is up — open a NEW Terminal window:
       curl http://127.0.0.1/health
   Expected: {"mode":"rust-supervisor","status":"ok", ...}

8. Log in with your Apple ID:
       curl -X POST http://127.0.0.1/login \
         -H 'content-type: application/json' \
         -d '{"username":"you@example.com","password":"your-password"}'
   (change the username/password to your own)

9. If you have 2FA enabled, you get a response code back; replace 123456 and run:
       curl -X POST http://127.0.0.1/login/2fa \
         -H 'content-type: application/json' \
         -d '{"code":"123456"}'

10. Confirm you are authenticated:
       curl http://127.0.0.1/me
    Expected: "state":"authenticated" (and "playback_ready": true)

11. Now you can close the terminals. Open OrpheusDL GUI → Settings →
    Apple Music → enable "Use wrapper on 127.0.0.1".
    Keep the wrapper container running while downloading (Docker Desktop
    play icon).

----------------------------------------------------------------------------
TROUBLESHOOTING - "FPS decrypt failed ... KDProcessResponseCKC status: -42812"
-------------------------------------------------------------------------------
If login and playback work but ALAC decryption fails with:

   wrapperd: decrypt client closed: {"detail":"FPS decrypt failed (first: Fairplay error. KDProcessResponseCKC status: -42812)","error":"decrypt_failed"}

and the wrapper startup log shows:

   loader: dlsym(_ZN21SVFootHillSessionCtrl16getPersistentKey...): undefined symbol

then the staged Apple Music libraries do not export the getPersistentKey symbol that
wrapper-v2's FPS key path needs. This is a known wrapper-v2 issue (issue #12).
It happens even with the exact recommended APK on both Intel and Apple Silicon,
so it is NOT a setup mistake on your side.

Working fix (from the issue): swap in the WorldObservationLog release libs for
your architecture, exactly as shown in step 5 above. The "docker rmi wrapper-v2:
No such image" error is harmless — the image is named after the compose project;
the --build flag rebuilds it regardless.

Then log in again (DELETE /login, then POST /login) and retry the download.

If you still see the undefined symbol after the swap, report it at:
https://github.com/glomatico/wrapper-v2/issues

----------------------------------------------------------------------------
gamdl requirement
----------------------------------------------------------------------------
The Apple Music module requires gamdl >= 3.8.5 (ships the compiled Rust decrypt engine):
   pip install -U gamdl

gamdl 3.8.2+ decrypts over the WV2D batch TCP protocol instead of HTTP POST /decrypt:
   - Wrapper URL (HTTP control API):   127.0.0.1  (port 80)
   - Wrapper decrypt host (TCP):       127.0.0.1
   - Wrapper decrypt port (TCP):       10020
These three fields are exposed in Settings > Apple Music.

Windows — quick start
----------------------------------------------------------------------------
0. Install Docker Desktop for Windows (WSL2 backend).
1. Get wrapper-v2 (Download ZIP, extract): https://github.com/glomatico/wrapper-v2
2. Download Apple Music 3.6.0-beta build 1109 (same link as step 2 above),
   move it into the folder, rename to apple-music.apkm.
3. In a CMD/PowerShell (Git Bash works too) inside the folder:
       bash tools/extract-libs.sh --bundle apple-music.apkm --arch x86_64
       bash tools/stage-system.sh --arch x86_64
       curl -fLo /tmp/wol-x86.zip "https://github.com/WorldObservationLog/wrapper/releases/download/wrapper.x86_64.latest/Wrapper.x86_64.latest.zip"
       unzip -oq /tmp/wol-x86.zip -d /tmp/wol-x86
       cp -a /tmp/wol-x86/rootfs/system/lib64/. rootfs/system/lib64/
       bash tools/stage-system.sh --arch x86_64
4. Make sure Docker Desktop is running, then:
       docker compose up --build
5. In a new CMD:
       curl http://127.0.0.1/health
       curl -X POST http://127.0.0.1/login -H "content-type: application/json" -d "{\"username\":\"you@example.com\",\"password\":\"your-password\"}"
   (change the credentials; if 2FA is required you get a response code, then:)
       curl -X POST http://127.0.0.1/login/2fa -H "content-type: application/json" -d "{\"code\":\"123456\"}"
       curl http://127.0.0.1/me
6. Open OrpheusDL GUI → Settings → Apple Music → enable "Use wrapper on
   127.0.0.1". Keep the container running while downloading.
